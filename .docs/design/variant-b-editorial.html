The tweak, in one line

Speaker labels and hairline rules replace chat bubbles. The result reads as a document — which is what an Obsidian panel sits next to all day — instead of as a messaging thread bolted onto a note-taking app.

Serif carries the answer

The assistant speaks in Newsreader at 15.5px; you speak in sans. The voice split is legible at a glance without a single avatar, colour or bubble. Claude's own serif is used only for the greeting — here it earns a bigger job.

The margin rail

Tool calls sit in an indented monospace ledger against a single hairline — present but subordinate, the way footnotes are. Running calls pulse the clay accent rather than spawning a spinner.

Composer as a colophon

No floating card. A heavy rule closes the page, a letterspaced state line prints the active context, and the input is set in serif so writing a prompt feels like writing a note.

The tweak, in one line

Same Claude colours, but hierarchy is carried by elevation instead of borders. Almost every hairline is replaced by a shadow, which is what lets the panel feel like an app layer floating above the vault rather than a pane cut into it.

The user turn goes loud

A clay gradient bubble with an asymmetric corner. It is the only saturated surface on screen, so your own instructions are findable when scrolling a long thread — the exact thing that gets lost in Claude's all-neutral transcript.

Tool calls as a timeline

A gradient rail connects the nodes, so a multi-step run reads as one continuous action instead of three unrelated rows. The active node pulses a clay halo — progress without a spinner.

Dark mode is first-class

Warm charcoal #17140f and #241f1b rather than a desaturated grey, so the clay accent stays warm instead of turning neon. The ambient wash at the top of the panel survives the theme flip.

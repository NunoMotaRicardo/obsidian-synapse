Palette — Claude, unmodified

Canvas #f0eee6, raised surfaces #faf9f5, ink #141413, clay accent #d97757. Tool status uses Claude's moss #788c5d rather than a generic green.

The serif greeting

Claude's single typographic gesture: a light serif line on an otherwise all-sans surface. Newsreader stands in for Claude's Tiempos. It appears only in the empty state — once a conversation starts, the panel is pure sans.

Composer as the centre of gravity

16px radius, one hairline border, a 2px shadow that deepens on focus. The footer carries the segmented agent control, an inline model picker and a circular clay send button — the same four-element rhythm Cowork uses.

What Synapse adds

Only what Obsidian requires: the active-note chip above the input, vault-scope chips, and a tool ledger under each assistant turn. All three borrow existing Claude components rather than inventing new ones.

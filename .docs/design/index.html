Synapse · design study

Making Synapse look like Claude

Three prototypes for the Synapse chat panel, built on Claude's brand palette and measured against the Claude Cowork surface. Variant A reproduces Claude exactly; B and C keep the palette but each apply one deliberate, non-subtle design move.

01

Where Synapse stands today

Synapse already ships the right colours — the vault's Synapse theme sets terracotta #d97757 on warm parchment, which is within a hair of Claude's clay on ivory. What differs is everything downstream of colour: density, radii, the weight given to the composer, and where hierarchy comes from.

Hierarchy Carried by 1px borders on nearly every surface. Carried by surface lightness and one 2px shadow; borders are rare.

02

Three prototypes

All three share the same palette and the same information architecture, so they can be compared on design alone. A is the control; B and C each change exactly one thing about where hierarchy comes from.

Variant A · the control

Claude Native

Claude Cowork, ported to the side panel with nothing invented. Exact palette, 16px composer card, segmented agent control, centred serif greeting. The safe answer to "make it look like Claude".

Open prototype
Variant B · typographic

Editorial

Same colours, but the transcript is set like a printed page: hairline rules and small-caps speaker labels instead of bubbles, the assistant answering in a serif, tool calls in a monospace margin rail.

Open prototype
Variant C · atmospheric

Luminous Clay

Same colours, but hierarchy comes from light: soft elevation instead of borders, a clay glow behind the mark, a composer floating over a scrim, tool calls drawn as a connected timeline, and a saturated clay bubble for your own turns.

Notes on the source material

Claude palette

Ink #141413, paper #faf9f5, canvas #f0eee6, manilla #f5e3c7; accents clay #d97757, slate blue #6a9bcc, moss #788c5d. Type is Styrene A with a Tiempos-class serif; DM Sans and Newsreader stand in here.

Synapse theme

From the configs vault: accent #d97757, parchment #faf8f5 / #f2ede7, warm dark #1a1714, DM Sans UI font. The theme is already Claude-adjacent — the prototypes shift only the two or three tokens where it diverges.

These are drafts, not a spec

Static HTML with hard-coded hex values. Nothing here maps to Obsidian CSS variables yet — that translation is the implementation step, and it is what decides how much of a chosen variant survives contact with other themes.

Every prototype has a dark mode

Use the toggle at the top of each page. Dark mode is where the variants diverge most: A stays neutral, B keeps its rules, C leans hardest on warm charcoal so the clay accent does not turn neon.

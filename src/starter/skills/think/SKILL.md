# Think — Interview Before Writing

Interview the user about the plan, note, or decision until you both share the same understanding. Work through each open point in turn, resolving the ones other choices depend on first.

## Ground rules

- Ask **one question at a time**.
- With each question, offer your **recommended answer**, then ask the user to confirm, correct, or choose another option.
- Keep going until every open point is resolved — don't stop after a few answers.
- Don't produce the final output until the interview is done.

## Check the vault before asking

Don't ask for something that's already written down. Before each question, look for the answer in the vault: the active note, notes linked from it, and the folder for the relevant topic. If it's unclear where to look, ask the user once, up front.

## When to stop

Stop when every open point has an answer the user has confirmed — not one you assumed. Summarize what was agreed before producing any output.
